# Pilot invitation drafts

Invitation templates for the owner. The [pilot report](report.md) records participants and results.
The current SOW calls for two independent providers and two pilot users.

## Independent provider

We are testing Provider Standard v1, a kit for paid API calls and delayed-job recovery on Stellar testnet.
Would you like to integrate an API you independently control? The pilot uses test tokens, not real payments.

Start with [the setup guide](https://github.com/AlgoriaLabs/stellar-agent-services/blob/main/docs/provider-setup-guide.md).
Keep control of your code, payout wallet and deployment. Never send a secret key or seed phrase. Record setup
time, where the guide was unclear and any help you needed. We will collect one paid testnet call, a verification
receipt and its registry reference, using a public participant alias agreed with you.

## User participant

We are testing how clearly an agent service explains its price, payment recipient, approval and result.
Would you try a testnet service and tell us where you get stuck? This uses test tokens. We will ask you to find
a service, review its terms, approve a payment and collect its result. Some sessions will also try recovering
the same paid job after an interrupted response.

With your agreement, evidence will use an alias and show only the necessary public testnet references.
Wallet secrets, private contact details, job tokens and signed payment payloads are excluded.
